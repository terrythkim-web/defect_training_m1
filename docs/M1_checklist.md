# M1 수동 확인 체크리스트 (라벨링 툴)

M1 완료 기준: 라벨링 툴만으로 프로젝트를 만들고, 이미지를 넣고, BBox/Polygon/SAM으로 라벨링해 YOLO 라벨까지 저장할 수 있다 (PRD 7장).
**Linux와 Windows 각각**에서 확인한다. 테스트 폴더는 공백과 한글이 들어간 경로를 쓴다 (예: `D:\검사 데이터\샘플 이미지`).

실행: `python -m defect_inspection.app`

## 1. 프로젝트 / 이미지 (F1)
- [ ] 새 프로젝트(Ctrl+N) → 한글·공백 경로 폴더 선택 → `project.yaml`, `images/`, `labels/` 생성
- [ ] 이미지 폴더 추가(Ctrl+I): PNG, JPG, JPEG, `.JPG`(대문자), BMP, TIF/TIFF 모두 들어오고 TXT 등은 무시
- [ ] 같은 이름(`a.png` + `a.jpg`)을 넣으면 `a_1.jpg`로 바뀌어 들어감
- [ ] 16bit TIFF가 너무 어둡거나 하얗지 않게 보임, 1채널 그레이 이미지 정상 표시
- [ ] 썸네일이 잠시 후 채워지고, 앱을 다시 열면 바로 보임(디스크 캐시)
- [ ] 필터: 전체 / 미라벨 / 라벨됨 / 제안 대기 / OK 이미지 각각 맞게 걸러짐
- [ ] 저장하지 않은 변경이 있으면 제목에 `*`, 닫을 때 저장 여부를 물음
- [ ] 프로젝트를 닫았다가 다시 열면(Ctrl+O) 클래스·이미지·라벨이 그대로

## 2. 캔버스 (F2.3)
- [ ] 휠 확대/축소가 마우스 위치 기준으로 동작, 200% 이상에서 픽셀이 또렷함
- [ ] 스페이스+드래그, 가운데 버튼 드래그로 이동
- [ ] 맞춤(Ctrl+0), 100%(Ctrl+1)
- [ ] 상태바 좌표가 이미지 픽셀 좌표와 일치(좌상단 0,0)
- [ ] 밝기·대비 슬라이더는 화면만 바뀌고 라벨/파일에 영향 없음, 초기화 버튼 동작
- [ ] A/D로 이전/다음 이미지, 4K 이미지에서도 화면이 멈추지 않음(처음 여는 큰 이미지는 "불러오는 중…" 후 표시)

## 3. 마킹 도구 (F2.1, F2.2, F2.5)
- [ ] BBox(B): 드래그로 생성, 이미지 밖으로 끌면 이미지 경계에서 잘림
- [ ] Polygon(P): 클릭으로 점 추가, 더블클릭 또는 Enter로 완료, Backspace로 마지막 점 삭제, Esc 취소
- [ ] 선택(V): 클릭 선택, 드래그 이동(이미지 밖으로 안 나감), 꼭짓점 핸들로 크기·모양 변경
- [ ] Delete 또는 지우개(E)로 삭제
- [ ] 숫자 1~9: 새 라벨 클래스 선택 + 선택된 라벨 클래스 변경, 라벨 색이 클래스 색을 따름
- [ ] 좌측 라벨 목록 선택 ↔ 캔버스 선택이 서로 따라감

## 4. 클래스 관리 (F2.2)
- [ ] `+ 클래스`로 추가, 중복 이름은 거부
- [ ] 이름 변경(버튼 또는 더블클릭): 라벨 목록·캔버스 태그에 바로 반영
- [ ] 색상 변경: 캔버스 라벨 색이 바로 바뀜

## 5. 자동 라벨 제안 (F2.8)
- [ ] SAM(S) 선택 시 처음 한 번 모델 다운로드/분석 메시지 후 "SAM 준비 완료"
- [ ] 클릭(포함) → 점선 제안 생성, 우클릭(제외)·추가 클릭으로 같은 제안이 갱신됨
- [ ] 드래그(박스)로 가늘고 긴 스크래치도 잡힘
- [ ] Enter 수락 → 실선 라벨, 다음 클릭은 새 대상 / Esc → 현재 제안 버림 / Backspace → 마지막 점 취소
- [ ] seg 프로젝트는 폴리곤, detect 프로젝트는 박스로 제안
- [ ] 오프라인 PC: 설정 > SAM 모델 > 파일 선택으로 로컬 `.pt` 지정 후 동작
- [ ] 제안이 있는 이미지에서: 선택 후 Enter 수락 / Backspace 거절, "score ≥ X 모두 수락", "이 이미지 제안 모두 거절"
- [ ] 제안은 점선 + 출처·score 표시, 이미지 목록에 "제안 N" 표시

## 6. 저장 / 되돌리기 (F2.4, F2.6)
- [ ] Ctrl+Z / Ctrl+Y로 그리기·이동·클래스 변경·수락·거절 모두 되돌리기/다시 실행
- [ ] 다른 이미지로 넘어가면 자동 저장되고 되돌리기 이력은 새로 시작
- [ ] 설정 > 자동 저장 간격(기본 30초)마다 "자동 저장됨" 표시, 0이면 꺼짐
- [ ] `labels/<이미지 이름>.json`(원본)과 `.txt`(YOLO) 생성, txt에 제안은 들어가지 않음
- [ ] 라벨 없는 이미지의 txt는 빈 파일
- [ ] 앱을 강제 종료해도 마지막 자동 저장까지의 라벨이 남아 있음
